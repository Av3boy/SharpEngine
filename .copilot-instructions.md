# Copilot Agent Policy — Commit Confirmation Required

Policy
- The Copilot CLI and any automated agents MUST NOT create git commits, amend commits, or push changes to this repository without explicit user confirmation from a human reviewer.
- All proposed changes must be presented to the user (diff or description) and explicitly approved before any commit is created.

How to request commits
- Provide the diffs or list of changed files and approve via an explicit message (e.g., "Approve commit").
- After approval, the Copilot agent may create a commit with the approved message and include the required Co-authored-by trailer.

Enforcement
- This file documents repository policy and should be respected by all Copilot agents and automation running in this repository.
